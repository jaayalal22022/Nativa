# Nativa — página web

Versión editable del sitio web de la joyería Nativa.

## Abrir el proyecto en Visual Studio Code

1. Descomprime el archivo ZIP.
2. Abre Visual Studio Code.
3. Selecciona **Archivo > Abrir carpeta**.
4. Elige la carpeta `Nativa_Web_VSCode_v1`.
5. Abre `index.html` para comenzar.

Puedes ver la página haciendo doble clic en `index.html`. Si tienes instalada la extensión **Live Server**, también puedes hacer clic derecho en `index.html` y seleccionar **Open with Live Server**.

## Archivos principales

- `index.html`: textos y estructura de la página.
- `styles.css`: colores, tamaños, diseño y adaptación a celulares.
- `script.js`: filtros, menú, fichas rápidas y mensajes interactivos.
- `assets/`: fotografías optimizadas de los productos.

## Cambiar la paleta de colores

Al inicio de `styles.css` encontrarás el bloque `:root`. Cambia únicamente estas variables para recolorear todo el sitio:

- `--color-ink`: negro principal.
- `--color-paper`: fondo marfil.
- `--color-surface`: fondo claro.
- `--color-accent`: terracota.
- `--color-accent-strong`: terracota oscuro.
- `--color-gold`: dorado.
- `--color-rose`: rosa complementario.
- `--color-muted`: textos secundarios.
